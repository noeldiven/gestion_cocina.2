# FunVal - Perfil con FormData

## Correr
npm install
npm run dev

## Antes de probar
Abre src/api.js y ajusta ENDPOINTS, LOGIN_MODE, LOGIN_FIELDS, PROFILE_FIELDS
según lo que diga https://api-funval-g6.onrender.com/docs

## Desplegar
- Vercel: importa el repo (vercel.json ya incluido). Build: `npm run build`, output: `dist`.
- Netlify: igual; public/_redirects ya está incluido.
